# Amazon-project
Amazon Clone

A front-end e-commerce project built with HTML, CSS, and JavaScript while following the SuperSimpleDev JavaScript course.

Live Demo: https://stevoadels.netlify.app/

About the Project

This project recreates parts of the Amazon shopping experience. I built it to practise JavaScript and understand how the different parts of an e-commerce website work together.

As a beginner in web development, I used the project to move beyond watching tutorials and gain practical experience writing, testing, and debugging code.

Features

Product listings

Shopping cart with quantity management

Delivery option selection

Order and payment summaries

Checkout and order submission using a backend API

Order history

Cart data persistence using browser local storage

Empty-cart handling

Technologies Used

HTML — page structure

CSS — styling and layout

JavaScript — interactivity and application logic

JavaScript modules — organizing code into separate files

Local Storage — preserving cart data in the browser

Backend API — submitting orders

Netlify — deployment

How to Try It

Visit the live demo.

Browse the available products.

Add products to your cart and adjust quantities.

Select delivery options and review the order summary.

Proceed to checkout and explore the order history.

Some features depend on the availability of the backend API.

What I'm Learning

Working on this project has helped me practise:

JavaScript fundamentals and DOM manipulation

Arrays, objects, functions, and modules

Event handling and updating the user interface

Working with APIs and asynchronous JavaScript

Using local storage to persist data

Debugging and connecting different parts of an application
